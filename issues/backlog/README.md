# backlog

The queue. The pair loop takes the first ripe Issue in running order: the slugs `ORDER` names, one per line (the developer's above `# groomed below`, and below it those `just groom` placed), then the rest in filename order. An Issue is ripe when its `waits_on` Issues are all done and it has no `Needs elaboration` section. `just groom` grooms each Issue here that has no `difficulty` and no `Needs elaboration` section, and places it below the marker without moving the rest; `just pair` takes the order as it stands. The loop sends an Issue back here, with that section, when it cannot be done as written.
