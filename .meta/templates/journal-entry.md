# Journal entry form

Copy the block below to the **end** of the journal. All three headings are
required.

They are required because of what a journal becomes without them: a bulleted
account of what was done, which git already holds. Encouraged headings do not
survive — a tiring writer drops them, and a tireless one never notices they are
missing.

```markdown
#### <a title someone would grep for>

**What was decided.** The decision, stated plainly. Not the diff; git has the diff.

**What was rejected, and why.** The part the code cannot record. If nothing was
rejected, this was not a decision and probably does not need an entry.

**What would falsify this.** What you would have to see to conclude it was wrong.
"Nothing could" means it is not a claim.
```

Optional, where they apply:

- **Evidence.** A measurement, with how it was taken and what the control was.
- **Supersedes.** Name the earlier entry. Never edit it.

**Route every finding in the same change that records it** (A13 — a finding that
exists only in a journal entry has not been made). If the entry establishes a
rule, that rule goes to the Charter in the same change. If it forecloses
something, it goes to a decision record.
